# Code of Conduct

This project should be a practical and respectful place to collaborate.

Participants are expected to:

- Communicate respectfully and assume good intent.
- Keep feedback focused on the work.
- Avoid harassment, threats, discrimination, and personal attacks.
- Respect privacy and avoid sharing private information without permission.

Maintainers may remove content, close issues or pull requests, or limit access
for behavior that undermines a productive project environment.

For conduct concerns, contact a Ralio maintainer privately. For security issues,
use the reporting process in [`SECURITY.md`](SECURITY.md).
